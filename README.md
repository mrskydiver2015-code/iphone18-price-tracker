# iPhone 18 Pro Max – Prisdashboard

Interaktiv prisjämförelse för iPhone 18 Pro Max 512 GB hos svenska återförsäljare och operatörer.

- Sorterbar tabell: butik/operatör, pris och besparing
- Nyckeltal: lägsta pris, största besparing, prisspridning
- Abonnemangserbjudanden från Tele2, Telia, Telenor och Tre

Öppna `index.html` eller se den live på Vercel. Priser observerade 2 oktober 2026.
